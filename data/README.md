# Data

This project uses the public corroded-pipeline burst-pressure dataset associated with:

Cai, J., Jiang, X., Yang, Y., Lodewijks, G., and Wang, M. (2022). *Data-driven Methods to Predict the Burst Strength of Corroded Line Pipelines Subjected to Internal Pressure*. Journal of Marine Science and Application, 21(2), 115–132. DOI: 10.1007/s11804-022-00263-0.

Public source repository:

https://github.com/jiejie168/pipeBurstPressure_prediction_dataDriven

## Expected local file

The research script expects the source workbook to be available in the working directory as:

```text
Data.xlsx
```

The implemented analysis uses 104 complete observations and selected original column positions `[2, 4, 5, 6, 9, 10, 13]` for measured failure pressure, UTS, outside diameter, wall thickness, corrosion length, corrosion depth, and defect shape.

The source dataset is not duplicated here so its provenance remains explicit. Download it from the original public repository and retain the original citation.

Proprietary inspection data and other restricted industry material should remain outside this repository.
